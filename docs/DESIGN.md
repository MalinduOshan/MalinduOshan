# Profile design and maintenance

This repository powers Malindu Oshan's GitHub profile. It uses GitHub
Flavored Markdown and local SVG assets; no web framework or deployment service
is required.

## Profile content

- `README.md` contains the verified biography, education, certifications,
  skills, projects, availability, and contact links.
- `assets/malindu.jpg` is the supplied profile photograph.
- `assets/hero.svg`, `assets/divider.svg`, and the social buttons provide the
  visual header and navigation.
- The contribution snake workflow uses the repository owner dynamically, so it
  will publish activity for `malinduoshan` when enabled in that profile
  repository.

Keep project status descriptions honest and update the contact links whenever
the public profile changes.
